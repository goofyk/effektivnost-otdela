# План оптимизации инструментов p1c

План построен только на находках этой проверки; напротив каждого пункта стоит
артефакт замера. Порядок: сначала то, без чего `p1c` не может работать с реальной
конфигурацией, потом то, что мешает доверять его выводам, потом качество выводов,
потом удобство вызова, и в конце — метрика успеха.

Сокращения путей: `<dump>` — выгрузка конфигурации, `<cfg>` — исходник конфигурации.
Артефакты: `reports/` (в git не входят), доказательственные разборы —
`docs/evidence/`.
