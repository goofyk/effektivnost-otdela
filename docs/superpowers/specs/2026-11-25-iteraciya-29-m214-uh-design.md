## 1. Вердикт M214: ограничение вывода типов, не пробел модели

Разведка по `HTTPServices/ОбучениеСУО/Ext/Module.bsl` (108 из 110 находок):

```
22  ДанныеСессии = Неопределено;
29  РегистрыСведений.СессииВебКабинетаСУ.ДанныеСессииЗапроса(Запрос, ДанныеСессии, КодОшибки, ...);
35  Права = ДанныеСессии.Права.Получить();
... ДанныеСессии.Пользователь ...
```

`ДанныеСессии` инициализируется `Неопределено`, затем заполняется **по ссылке** методом
`ДанныеСессииЗапроса` (out-параметр `ДанныеСессии`). Анализатор не отслеживает мутацию
by-ref-параметра, поэтому тип базы остаётся `Неопределено`, а член `.Пользователь` — это
свойство структуры сеанса, возвращаемой этим методом. Находка честна: `why` уже называет
«тип не определён — Неопределено; объявления типа в файле нет».

**Вердикт:** M214 — не пробел модели/книги и не неверный владелец, а **ограничение вывода
типов** (межпроцедурный вывод через out-параметр не реализован). Закрыть «реестром имён» нельзя
(имя `Пользователь` не принадлежит типу `Неопределено`); закрытие — отдельная крупная фича
(вывод типов через by-ref), не этой серии. M214 остаётся кандидатом-ограничением, вердикт
дописывается к строке §10.1, новый номер дефекта не заводится.
