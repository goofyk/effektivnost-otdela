**Goal:** Заполнить `why` у каждой METHOD-находки тремя семействами (модель, неизвестная база, канал), не меняя ни одного решения и ни одной тройки, и снять замер 88.

Решение о находке не трогается: правка только заполняет `hint`/`why`, поэтому наборы `(code, file, line)` обязаны совпасть с замером 87. Таблица корзин строится зондом по артефакту 88.

## Review Focus

1. **Известный тип, нет имени.** База — модельный тип (`Строка`, `Массив`, `ТабличныйДокумент`): `why` обязан называть тип и отсутствие имени, а не «тип не определён». Тест — Task 73 (б)–(г).
2. **`Неопределено` из разных присваиваний.** `В = Неопределено` и другие написания: `why` называет происхождение. Тест — Task 73 (а), (д).
3. **Молчание не ломается.** Параметр и переменная `Для каждого` по-прежнему не дают находки. Тест — Task 73 (и).
4. **Канал не переписывается.** Находка с известным каналом сохраняет свой `why`, а не получает модельный. Тест — Task 73 (е).
5. **Тройки и текст.** Объяснение не смеет ни снять, ни добавить находку. Тест — Task 73 (ж); гейт замера 88.
6. **34 канальные находки без `why`.** Получают непустой `why` без выдуманного знания. Тест — Task 73 (к), проверка зондом.
